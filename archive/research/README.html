Research archive

Earlier CoA experiments, integration receipts, notebook exports and figures are retained here for traceability. The main workflow is independent of this archive.

Historical JSON receipts and source manifests retain their original bytes, paths and hashes. Their recorded paths describe the original experiment, not a current installation. The repository layout relocation record explains moved files without rewriting scientific evidence.

Use a case study safely

The reviewed twelve-phantom CoA recipes are under configs/case-studies/coa/phantoms/ and the project index is configs/case-studies/coa/project.json. Start with case 260602, replace source paths, select fresh output revisions and repeat anatomical and parameter review. Model INIs under this archive are historical examples; the public initializer generates a separate editable model.ini for the demo workflow.

Commands in narrative guides point to the reorganized entry points. This does not make an earlier signed run portable: frozen dependency bytes, raw data locations and experiment locks still describe that run. Keep existing releases unchanged and create a new reviewed revision to rerun experiments.

Shared implementation modules remain in src/ because advanced workflows and regression tests still depend on them. Generated data and model outputs remain under ignored outputs/ and are not included in this source archive. Source code and scientific evidence are separate from storage backups.
