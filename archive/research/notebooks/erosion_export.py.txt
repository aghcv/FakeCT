"""## 1. From a closed surface to a binary voxel array

An STL file stores a surface as triangles. It does not directly identify inside voxels. FakeCT:

1. creates a grid around the centered mesh;
2. computes the physical coordinate of each voxel center;
3. evaluates a mesh winding number at each center; and
4. labels `winding_number > 0.5` as inside.

The essential production idea is:

```python
WN = igl.fast_winding_number_for_meshes(vertices, faces, query_points)
inside = WN.reshape((N, N, N)) > 0.5
surface = binary_dilation(inside) ^ inside
outside = ~(inside | surface)
```

**Coordinate warning:** FakeCT volumes are stored in array order `(z, y, x)`, although geometric points are usually written `(x, y, z)`.

## 2. Begin in 2D: Boolean arrays and bitwise operations

A binary image is a set of `True` pixels.

| NumPy expression | Set idea | Meaning for masks |
|---|---|---|
| `A & B` | intersection | true in both |
| `A \| B` | union | true in either |
| `~A` | complement | not in A |
| `A ^ B` | symmetric difference | changed between A and B |

Use `&` and `|` for NumPy arrays. Python's words `and` and `or` do not perform element-by-element operations.
"""

"""### 2.1 Morphology is an operation across shifted copies

Four-neighbor dilation asks whether the center **OR** north, south, west, or east was `True`. Four-neighbor erosion asks whether the center **AND** all four neighbors were `True`.

```text
          north
            |
west --- center --- east
            |
          south
```

"""

def neighbors4(mask):
    '''Return north, south, west, and east arrays aligned with mask.'''
    north = np.pad(mask[:-1, :], ((1, 0), (0, 0)), constant_values=False)
    south = np.pad(mask[1:, :], ((0, 1), (0, 0)), constant_values=False)
    west = np.pad(mask[:, :-1], ((0, 0), (1, 0)), constant_values=False)
    east = np.pad(mask[:, 1:], ((0, 0), (0, 1)), constant_values=False)
    return north, south, west, east

def dilate4(mask):
    north, south, west, east = neighbors4(mask)
    return mask | north | south | west | east

def erode4(mask):
    north, south, west, east = neighbors4(mask)
    return mask & north & south & west & east

eroded_2d = erode4(vessel_2d)
dilated_2d = dilate4(vessel_2d)

"""### 2.2 Constrain the operation to an ROI

Preserve the original outside the ROI and insert the candidate result only inside:

```python
result = (original & ~roi) | (candidate & roi)
```

This is the core connection between ROI selection and bitwise operations.

"""

def circular_roi_2d(shape_yx, center_yx, radius):
    y, x = np.indices(shape_yx)
    cy, cx = center_yx
    return (y - cy) ** 2 + (x - cx) ** 2 <= radius ** 2

def edit_binary_2d(mask, roi, operation, iterations=1):
    result = mask.copy()
    step = {"erosion": erode4, "dilation": dilate4}[operation]
    for _ in range(iterations):
        candidate = step(result)
        result = (result & ~roi) | (candidate & roi)
    return result

roi_2d = circular_roi_2d(vessel_2d.shape, center_yx=(7, 14), radius=5)
operation_iterations = 1 if ASSIGNED_TRACK == "erosion" else 2
assigned_binary_result = edit_binary_2d(
    vessel_2d, roi_2d, ASSIGNED_TRACK, iterations=operation_iterations
)

"""### The two tracks are intentionally asymmetric

**Erosion / stenosis releases artery pixels**

```python
released = old_artery & ~new_artery
```

A recipient tissue must fill each released location. The algorithm needs neighbor evidence, tie-breaking, protected labels, and an unresolved output.

**Dilation borrows surrounding pixels**

```python
requested_borrow = new_artery & ~old_artery
```

Each requested location already has a donor label. The algorithm needs donor eligibility, protected labels, blocked requests, and per-label audit counts.

## 4E. Erosion track - first-pass 2D release algorithm

Complete this track only if `ASSIGNED_TRACK == "erosion"`.

For each released artery pixel:

1. inspect north, south, west, and east neighbors;
2. exclude background, artery, and protected labels;
3. select the valid label with the largest neighbor count;
4. break a count tie using `recipient_priority` order;
5. leave the artery unchanged and mark `unresolved=True` if there is no valid recipient; and
6. change nothing outside `released_mask`.
"""

def release_pixels_2d(
    label_volume,
    released_mask,
    artery_id,
    recipient_priority,
    protected_labels,
    max_search_radius=2,
):
    """
    Assign released artery pixels to nearby eligible tissues.

    First pass:
    - Check the four direct neighbors.
    - Use majority vote, then recipient priority for ties.

    Controlled second pass:
    - Only if there is no valid direct neighbor, search outward by
      increasing square-ring radius up to max_search_radius.
    - Use the closest ring that contains valid tissue labels.
    - If no valid tissue is found, keep the artery label and mark
      the pixel unresolved.
    """
    updated_labels = label_volume.copy()
    unresolved_mask = np.zeros(label_volume.shape, dtype=bool)

    rows, cols = label_volume.shape

    # Smaller rank means higher priority during a tie.
    priority_rank = {
        label: rank
        for rank, label in enumerate(recipient_priority)
    }

    def choose_recipient(vote_counts):
        """Choose majority label; use priority only for tied labels."""
        largest_vote_count = max(vote_counts.values())

        tied_labels = [
            label
            for label, count in vote_counts.items()
            if count == largest_vote_count
        ]

        return min(
            tied_labels,
            key=lambda label: (
                priority_rank.get(label, len(recipient_priority)),
                label,
            ),
        )

    def add_valid_vote(vote_counts, neighbor_row, neighbor_col):
        """Add a vote only when a neighbor is an eligible recipient."""
        if not (
            0 <= neighbor_row < rows
            and 0 <= neighbor_col < cols
        ):
            return

        neighbor_label = int(label_volume[neighbor_row, neighbor_col])

        if neighbor_label == 0:
            return

        if neighbor_label == artery_id:
            return

        if neighbor_label in protected_labels:
            return

        vote_counts[neighbor_label] = (
            vote_counts.get(neighbor_label, 0) + 1
        )

    for row, col in np.argwhere(released_mask):

        # ---------------------------------------------------------
        # First pass: inspect only north, south, west, and east.
        # ---------------------------------------------------------
        direct_votes = {}

        direct_neighbors = [
            (row - 1, col),  # north
            (row + 1, col),  # south
            (row, col - 1),  # west
            (row, col + 1),  # east
        ]

        for neighbor_row, neighbor_col in direct_neighbors:
            add_valid_vote(
                direct_votes,
                neighbor_row,
                neighbor_col,
            )

        if direct_votes:
            updated_labels[row, col] = choose_recipient(direct_votes)
            continue

        # ---------------------------------------------------------
        # Second pass: search outward one square ring at a time.
        # This starts with diagonal neighbors at radius 1.
        # ---------------------------------------------------------
        found_recipient = False

        for radius in range(1, max_search_radius + 1):
            ring_votes = {}

            for row_offset in range(-radius, radius + 1):
                for col_offset in range(-radius, radius + 1):

                    # Keep only pixels on the current outer ring.
                    if max(abs(row_offset), abs(col_offset)) != radius:
                        continue

                    add_valid_vote(
                        ring_votes,
                        row + row_offset,
                        col + col_offset,
                    )

            # Use the closest radius containing eligible tissue.
            if ring_votes:
                updated_labels[row, col] = choose_recipient(ring_votes)
                found_recipient = True
                break

        # No eligible recipient was found in either pass.
        if not found_recipient:
            unresolved_mask[row, col] = True

    return updated_labels, unresolved_mask

def run_recipient_policy_tests():
    artery_id = 9

    # ---------------------------------------------------------
    # Test 1: A clear neighbor majority should beat priority.
    # ---------------------------------------------------------
    majority_labels = np.array(
        [
            [0, 2, 0],
            [2, 9, 3],
            [0, 2, 0],
        ],
        dtype=np.uint8,
    )

    majority_mask = np.zeros_like(majority_labels, dtype=bool)
    majority_mask[1, 1] = True

    updated, unresolved = release_pixels_2d(
        majority_labels,
        majority_mask,
        artery_id=artery_id,
        recipient_priority=[3, 2],
        protected_labels=set(),
    )

    # Label 2 has three votes, while label 3 has one vote.
    assert updated[1, 1] == 2
    assert not unresolved[1, 1]

    print("Test 1 passed: neighbor majority beats tissue priority.")

    # ---------------------------------------------------------
    # Test 2: Priority should resolve an exact tie.
    # ---------------------------------------------------------
    tie_labels = np.array(
        [
            [0, 2, 0],
            [3, 9, 2],
            [0, 3, 0],
        ],
        dtype=np.uint8,
    )

    tie_mask = np.zeros_like(tie_labels, dtype=bool)
    tie_mask[1, 1] = True

    updated, unresolved = release_pixels_2d(
        tie_labels,
        tie_mask,
        artery_id=artery_id,
        recipient_priority=[3, 2],
        protected_labels=set(),
    )

    # Labels 2 and 3 each have two votes.
    # Label 3 appears first in recipient_priority.
    assert updated[1, 1] == 3
    assert not unresolved[1, 1]

    print("Test 2 passed: recipient priority resolves a tie.")

    # ---------------------------------------------------------
    # Test 3: A protected label cannot receive the pixel.
    # ---------------------------------------------------------
    protected_case = np.array(
        [
            [0, 4, 0],
            [4, 9, 2],
            [0, 4, 0],
        ],
        dtype=np.uint8,
    )

    protected_mask = np.zeros_like(protected_case, dtype=bool)
    protected_mask[1, 1] = True

    updated, unresolved = release_pixels_2d(
        protected_case,
        protected_mask,
        artery_id=artery_id,
        recipient_priority=[4, 2],
        protected_labels={4},
    )

    # Label 4 has more votes but is protected, so label 2 must win.
    assert updated[1, 1] == 2
    assert not unresolved[1, 1]

    print("Test 3 passed: protected labels are excluded.")

    # ---------------------------------------------------------
    # Test 4: No valid neighbor should produce an unresolved pixel.
    # ---------------------------------------------------------
    no_recipient_labels = np.array(
        [
            [0, 4, 0],
            [4, 9, 4],
            [0, 4, 0],
        ],
        dtype=np.uint8,
    )

    no_recipient_mask = np.zeros_like(
        no_recipient_labels,
        dtype=bool,
    )
    no_recipient_mask[1, 1] = True

    updated, unresolved = release_pixels_2d(
        no_recipient_labels,
        no_recipient_mask,
        artery_id=artery_id,
        recipient_priority=[4, 2],
        protected_labels={4},
    )

    # The artery label should remain until a later review or second pass.
    assert updated[1, 1] == artery_id
    assert unresolved[1, 1]

    print("Test 4 passed: pixel is marked unresolved when no recipient exists.")

    # ---------------------------------------------------------
    # Final safety check: locations outside the mask cannot change.
    # ---------------------------------------------------------
    assert np.array_equal(
        updated[~no_recipient_mask],
        no_recipient_labels[~no_recipient_mask],
    )

    print("\nAll recipient-selection policy tests passed.")


run_recipient_policy_tests()
